\# 🚀 AI Resume Analyser



An AI-powered web application that analyzes resumes (PDF/DOCX) and provides instant feedback on skills, strengths, weaknesses, and improvement suggestions — powered by Google's Gemini AI.



\## 🔗 Live Demo



\- \*\*Frontend:\*\* https://ai-resume-analyser-swart-nine.vercel.app

\- \*\*Backend API Docs:\*\* https://ai-resume-analyser-2pfu.onrender.com/docs



> Note: Backend is hosted on Render's free tier, so it may take 30-50 seconds to "wake up" on the first request after inactivity.



\## ✨ Features



\- 📄 Upload resume in PDF or DOCX format

\- 🤖 AI-powered analysis using Google Gemini API

\- 📊 Overall score out of 100

\- 🛠️ Automatically extracted skills

\- ✅ Strengths identification

\- ⚠️ Weaknesses and areas of improvement

\- 💡 Actionable suggestions to improve the resume

\- 🎨 Clean, responsive UI with drag-and-drop upload



\## 🛠️ Tech Stack



\*\*Backend:\*\*

\- FastAPI (Python)

\- Google Gemini API (gemini-3.5-flash-lite)

\- pdfplumber \& python-docx for resume parsing

\- Uvicorn (ASGI server)



\*\*Frontend:\*\*

\- HTML, CSS, JavaScript (vanilla, no framework)

\- Fetch API for backend communication



\*\*Deployment:\*\*

\- Backend → Render

\- Frontend → Vercel

\- Version Control → GitHub
